# Task Management App

## 1. Project Overview
The Task Management App is a simple application designed to help users create, organize, track, and manage their daily tasks efficiently. It helps users monitor task progress and improve productivity.

## 2. Objectives
- Organize tasks in one place.
- Track tasks using To Do, In Progress, and Done stages.
- Improve productivity and time management.
- Provide a simple and user-friendly interface.

## 3. Scope
The application focuses on basic task creation, task organization, status tracking, and progress monitoring. Additional features may be added in future versions.

## 4. Key Features
- Create and manage tasks.
- View all tasks in one place.
- Update task status.
- Organize tasks by progress.
- Simple and user-friendly interface.

## 5. Technologies Used
- Frontend: HTML, CSS, JavaScript
